# 🌿 HerbiVerse

> An Interactive Learning & Information Hub for herbal plants 🌱

HerbiVerse helps users explore the medicinal world of herbs through detailed info, immersive 2D/3D plant models, and personalized plant care tips. Built to educate and empower green enthusiasts.

## 🚀 Features

- Explore 2D & 3D visualizations of plants
- Searchable plant database with descriptions & scientific names
- Admin dashboard for CRUD operations on plant info
- Virtual Herbal Garden with immersive UI

## 🧠 Tech Stack

- **Frontend:** React, TailwindCSS, Framer Motion, Three.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Others:** React Router, Axios
